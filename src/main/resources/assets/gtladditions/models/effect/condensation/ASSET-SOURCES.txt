Each OBJ adds a usemtl directive for Forge's standard OBJ loader. The model JSON
overrides the original material library with geometry.mtl. Only baked positions
are copied to the VBO; procedural shaders still provide all visible colors.

GTLAdditions adaptation (2026-10-18):
Minecraft 1.20.1 GLSL 150 and cached vertex buffers; ice-white/cyan core,
dark blue inner shell; center and size fit the antientropy condensation center.
The shell diameter is 11 blocks. Machine-owned rotation pauses while idle;
surface color flow continues using the world's clock while formed.
GlowRing and the protomatter particle beam are intentionally omitted.
