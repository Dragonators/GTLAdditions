# Suprachronal Assembly Line Resonatic Circuit Assembly Module

<BlockImage id="gtladditions:suprachronal_assembly_resonatic_circuit_assembly_module" scale="8" />

<Column gap="15" fullWidth={true}>

<Column gap="2" fullWidth={true}>

* <ItemLink id="gtladditions:suprachronal_assembly_resonatic_circuit_assembly_module" /> is a module machine for <ItemLink id="gtceu:suprachronal_assembly_line" />, used to mass-produce ULV through UIV Resonatic circuits at lower cost (5 circuits per operation).
* It must be installed in a module slot on <ItemLink id="gtceu:suprachronal_assembly_line" />, and its parallel limit is determined by the host's parallel control hatch.
* The machine supports laser input, perfect overclocking, and batch processing, with 60% shorter recipe duration (0.4x).
