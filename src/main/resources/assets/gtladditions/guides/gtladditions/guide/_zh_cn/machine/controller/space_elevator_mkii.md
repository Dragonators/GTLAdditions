# 太空电梯MK2

<BlockImage id="gtladditions:space_elevator_mkii" scale="8"/>

<Column gap="15" fullWidth={true}>

* <ItemLink id="gtladditions:space_elevator_mkii" /> 最多可以连接 56 个太空电梯模块。

## 进阶电梯模块

* [星穹聚合枢纽](astral_convergence_nexus.md)：处理太空组装模块配方。
* [星云收割者](nebula_reaper.md)：处理太空采矿与太空钻井配方。

## MK2 加成

进阶模块的等级由太空电梯结构中的动力模块决定。普通太空电梯提供的最大并行为 `8^(模块等级-1)`；连接到 <ItemLink id="gtladditions:space_elevator_mkii" /> 时改为 `12^(模块等级-1)`。
