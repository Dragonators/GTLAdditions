# 太素衍化枢纽

<Row>
    <BlockImage id="primordial_evolution_nexus" scale="8"/>
</Row>

* 将石化、木化和生化产线统合在一起的综合性原料生产机器。
* 机器支持跨配方并行，基础线程数为 128。
* 结构允许安装 <ItemLink id="gtladditions:thread_modifier_hatch" />；其中每个 <ItemLink id="gtladditions:astral_array" link={false} linkColor={true} /> 会在基础线程之外额外增加 256 线程。
