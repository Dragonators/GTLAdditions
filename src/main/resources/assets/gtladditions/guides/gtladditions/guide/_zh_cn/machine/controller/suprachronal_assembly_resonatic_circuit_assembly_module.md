# 超时空装配线磁共振电路组装模块

<BlockImage id="gtladditions:suprachronal_assembly_resonatic_circuit_assembly_module" scale="8" />

<Column gap="15" fullWidth={true}>

<Column gap="2" fullWidth={true}>

* <ItemLink id="gtladditions:suprachronal_assembly_resonatic_circuit_assembly_module" /> 是 <ItemLink id="gtceu:suprachronal_assembly_line" /> 的模块机器，用来以更低成本批量生产 ULV 至 UIV 级磁共振电路（每次产出 5 个）。
* 需安装在 <ItemLink id="gtceu:suprachronal_assembly_line" /> 的模块位，并行上限由主机的并行控制仓决定。
* 机器支持激光仓输入、无损超频与批处理，且配方耗时减少 60%（0.4 倍）。
