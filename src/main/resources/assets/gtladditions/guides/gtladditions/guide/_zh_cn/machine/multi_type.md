# 跨配方模式并行

<Column gap="15" fullWidth={true}>

<Column gap="2" fullWidth={true}>

支持跨配方模式并行的机器可以在同一轮工作中处理多个类别的配方，无需手动切换当前配方类别。

</Column>

<Column gap="2" fullWidth={true}>

* 这类能力与普通并行不同：普通并行主要放大单个配方的执行规模，跨配方模式并行则允许多个配方类别共同参与同一轮工作。
* <ItemLink id="gtladditions:forge_of_the_antichrist" /> 可以在超维度熔炼、恒星热能熔炼、终极物质锻造之间进行跨配方并行。
* <ItemLink id="gtladditions:apocalyptic_quantum_warp_matrix" /> 可以在量子操纵者与奇点压缩之间进行跨配方并行。
* <ItemLink id="gtladditions:exotic_chemical_complex" /> 三级可让不同工艺单元处理大化反与化扭配方，达到与跨配方模式并行类似的效果。
* 实际能同时推进多少配方，仍会受到机器线程、并行能力、输入与能源供应的限制。

</Column>

</Column>
