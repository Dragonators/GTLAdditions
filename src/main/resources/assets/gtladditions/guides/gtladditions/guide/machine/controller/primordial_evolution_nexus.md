# Primordial Evolution Nexus

<Row>
    <BlockImage id="primordial_evolution_nexus" scale="8"/>
</Row>

* A comprehensive raw-material production machine integrating petrochemical, wood-processing, and biochemical production lines.
* The machine supports cross-recipe parallelization with 128 base threads.
* Its structure accepts an <ItemLink id="gtladditions:thread_modifier_hatch" />; each <ItemLink id="gtladditions:astral_array" link={false} linkColor={true} /> adds 256 threads beyond the base thread count.
