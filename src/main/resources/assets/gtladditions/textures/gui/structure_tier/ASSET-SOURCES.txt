Structure upgrade page buttons and icon
=======================================

button_normal.png, button_hover.png, button_pressed.png and button_disabled.png
are adapted from GTLCore's wireless panel buttons (button_normal.png,
button_hover.png, button_disabled.png in assets/gtlcore/textures/gui/wireless/),
cut to 18x14 with 3-pixel nine-slice edges. Normal keeps the original pixels,
hover the original hover palette; pressed reverses the inner lighting and
disabled reduces the highlights. The red cross of the original disabled
button is left out.

Source project: https://github.com/GNSW/GTLCore
Source artifact: gtlcore-1.2.3.3.jar
Source JAR SHA-256: 284a59caddb060cdba7d8774cd25924c7ef2cbecd813e1354c37248662041ebf
Original contributors: GTLCore contributors.

Source license: GNU Lesser General Public License v3, as declared by the
source JAR's META-INF/mods.toml; the adapted buttons carry the same license.
Full texts: assets/gtladditions/models/effect/condensation/LGPL-3.0.txt and
GPL-3.0.txt in the same directory.

icon.png is an original 16x16 drawing made for this mod (a machine facade with
a controller screen and a small green up-arrow); no third-party pixels.
