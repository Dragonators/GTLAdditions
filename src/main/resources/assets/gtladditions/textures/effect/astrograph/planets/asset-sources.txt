All 240 PNG files are byte-for-byte upstream copies, checked against the
upstream Git blob hashes. The 40-planet pool follows DimensionHelper and
TileEntityEyeOfHarmony.BLACKLISTED_PLANETS at this commit.

Each lower-case subdirectory maps to the original dimension abbreviation:
Ne, TF, Eg, Mo, De, Ma, Ph, As, Ca, Ce, Eu, Ga, Rb, Io, Me, Ve, En, Mi, Ob, Ti,
Ra, Pr, Tr, Ha, KB, MM, Pl, BC, BE, BF, CB, TE, VB, An, Ho, Mh, MB, Np, Se, DD

Mapping: <dimension>/<face>.png comes from <Dimension>_<face>.png.
Minecraft 1.20 models map bottom/top/back/front/left/right to
down/up/north/south/west/east respectively. Model JSON is authored locally.

The shared planet_cube model flips the bottom-face V coordinate to match
EOHRenderingUtils.emitBlock (GTNH with its bottom-face UV fix enabled).
